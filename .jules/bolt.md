## 2024-05-19 - PyTorch Grid Sampling Coordinate Generation & View Vectorization Optimization
**Learning:** Element-wise boolean masking and scalar division limits precision scalability in batched perspective mapping (`warp_perspective_torch`). `grid_sample` can natively handle padding modes if out-of-bound indices are directly passed. Vectorizing loop iteration structures along batched components using flattened tensors (`.reshape(B * V, ...)` over `for` loops) leads to tremendous speed gains on geometric forward processing logic. Furthermore, precision `float32` mixed with `torch.bmm` is significantly more performant than base loop `@` logic.
**Action:** Always prefer manipulating mathematically invalid projections manually and feeding explicit border limits over employing boolean mapping/clamp structures for coordinates going to `grid_sample`. Maximize model component parallelization by reshaping multi-view coordinates into flat batches before geometric evaluation.
