## 2026-05-30 - [Batched Multi-View Operations]
**Learning:** In multi-view models (like MVDetLikeNet), processing the multi-view dimension in a Python loop for CNN operations (backbone, projection, heads) is a massive performance bottleneck due to under-utilizing GPU parallelism. Batch Normalization behavior also subtly changes when batching views, which is generally desired for multi-view tasks. Using `.reshape()` instead of `.view()` is safer when flattening batch and view dimensions to avoid RuntimeError from non-contiguous tensors.
**Action:** When working on multi-view architectures, flatten the batch and view dimensions (`B * V`) to execute feature extraction and spatial operations concurrently. Always use `.reshape()` for safety when flattening dimensions unless you can guarantee tensor contiguity.
