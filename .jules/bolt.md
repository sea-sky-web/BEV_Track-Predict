## 2024-06-25 - PyTorch Grid Sampling Out-of-Bounds Optimization
**Learning:** For PyTorch grid sampling and perspective warping, pushing invalid coordinates out-of-bounds (e.g., `invalid = z <= 1e-6; coords = torch.where(invalid, 2.0, coords)`) is significantly faster than using slow mask-filling operations like `torch.nan_to_num`. Additionally, using `float32` coordinate arithmetic with `torch.bmm` provides a huge performance boost over `float64` and `@` operator when computing inverse projections on CPU.
**Action:** When implementing spatial transformations or grid sampling in PyTorch, leverage `grid_sample`'s native `padding_mode` by forcing invalid coords out-of-bounds rather than explicitly filling nan values, and prefer `float32` + `torch.bmm` for batched tensor math.
