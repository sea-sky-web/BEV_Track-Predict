## 1. Constant-Velocity Baseline 结果

| 指标 | 数值 | 说明 |
|------|:----:|------|
| **ADE** | **0.1555 ± 0.0360 m** | 全轨迹平均位移误差 |
| **FDE** | **0.2693 ± 0.0756 m** | 最终帧位移误差 |

| N_trajectories | 498 | val split 全部可预测轨迹 |
| N_windows | 33 | 滑动窗口数 |

### 结果解读

- **ADE 0.155m ≈ 15.5cm**：行人一步长约 0.6-0.7m，恒速外推 2 秒的误差仅为半步以内
- **FDE 0.269m ≈ 26.9cm**：2 秒后的终点误差约为一步的 1/3
- **FDE/ADE 比值 = 1.73**：接近理论值 2.0（线性增长），说明误差以近似线性方式累积，WildTrack 行人运动较为平稳

### 与文献对比（相似场景参考）

| 方法 | 数据集 | Horizon | ADE | FDE | 备注 |
|------|--------|:-------:|:---:|:---:|------|
| Const-Vel (ours) | WildTrack | 2.0s | 0.155m | 0.269m | 多视角 BEV 世界坐标 |

注意：直接对比有局限（horizon 不同、坐标系不同、场景密度不同），但量级可作参考。

### 关键发现

1. **WildTrack 行人运动非常平稳**：2s horizon 的恒速 ADE 仅 15.5cm
2. **这意味着学习模型的提升空间有限**：即使完美预测，也只能在 15.5cm 基础上做改善
3. **误差中多少来自转向/加减速？** FDE/ADE≈1.73（理论恒速=2.0），说明有轻微转向，但不大
4. **498 predictions / 33 windows = 平均 15.1 人/窗口**：WildTrack 行人密度中等

## 3. 方向选择分析

### 选项 A：轨迹预测方向（MLP / Social-STGCNN）

**目标**：超越恒速 baseline 的 ADE 0.155m

**优势**：
- 个体轨迹是最直接的下游输出，论文叙事清晰
- 可以展示 BEV 多视角 → tracking → prediction 完整链路
- 与 research plan Section 11.2 对齐

**劣势**：
- 恒速 baseline 已经很强（0.155m），改进空间小（可能只能到 0.10-0.12m）
- WildTrack 只有 313 个训练窗口，学习型模型容易过拟合
- 类似 ConvLSTM 在场预测上的失败经验：数据太少 + 信号太弱
- 除非有社会交互（避碰、跟随），否则简单 MLP 不一定超过恒速

**适用条件**：
- 如果 ADE > 0.3m，说明恒速假设不成立，学习模型有空间 → **不适用**（ADE=0.155m 太低了）
- 如果存在明显的群体交互模式 → 需要进一步分析

### 选项 B：深耕场预测方向（改进 ConvLSTM / 分辨率优化）

**目标**：在 bev_down=16 (AUPRC=0.663) 基础上进一步提升

**优势**：
- bev_down=16 已验证可行（AUPRC=0.663 > Advection baseline）
- 场预测对 tracker 误差鲁棒（L1→L3 仅降 14%）
- 与论文主方向（occupancy-flow field prediction）一致
- 分辨率消融有清晰的研究故事

**劣势**：
- bev_down=16 (0.4m cell) 定位精度有限（空间量化误差 0.2m）
- 与轨迹 ADE 0.155m 相比，0.4m 的 cell 本身就引入了不可消除的离散化误差
- ConvLSTM 在原分辨率完全失败，只在低分辨率有效

**适用条件**：
- 场预测更适合高密度场景（拥挤交叉、群体流动）
- WildTrack 的密度（~20人/帧）介于稀疏和高密度之间

### 选项 C：改进 Tracker + 轻量预测组合

**目标**：解决 L2→L3 的 IDSW/FP 退化，同时做简单的轨迹外推

**优势**：
- L2→L3 FP surge (8→56) 是明确的工程问题，有清晰的改进路径
- 改进 tracker 直接提升端到端系统质量
- 不需要大量训练数据

**劣势**：
- Tracker 改进是工程优化，研究贡献有限
- MOTA 0.7866 到 0.8841 的差距主要来自 FP，可能通过参数调优解决

## 4. 推荐方向

### 推荐：选项 C (改进 Tracker) + 选项 A (轻量轨迹预测) 组合

**理由**：

1. **恒速 ADE=0.155m 说明 WildTrack 行人运动太平稳**，重型学习模型（STGCNN、Transformer）很难显著超越。这与 ConvLSTM 在场预测上的失败一致：数据太少、信号太弱。

2. **Tracker FP 问题是最有影响力的改进点**：L3 MOTA 从 L2 的 0.884 降到 0.787，修复后可以直接提升端到端质量。

3. **轻量轨迹预测（2-layer MLP）** 作为"最小学习改进"尝试：
   - 输入：历史 4 帧位置 + 速度
   - 输出：未来 4 帧位置
   - 如果无法超越恒速 baseline（验证 loss < 恒速 loss），则记录负实验并停止
   - 如果超越，获得论文所需的"learning > heuristic"对比

4. **场预测路线暂缓**：在 WildTrack 上已经证明了可行性（bev_down=16），但继续优化的收益有限。等到更高密度数据（Hub 场景标定后）再重启。

### 具体执行计划

| 步骤 | 内容 | 预期时间 |
|:---:|------|:---:|
| 1 | Tracker 参数调优：dist_gate, max_age, min_hits 网格搜索 | 1 次 pipeline run |
| 2 | 分析 L3 的 18 次 IDSW 根因（哪些帧、哪些行人） | 分析代码 |
| 3 | 2-layer MLP 轨迹预测器实现 + 训练 | 1-2 天 |
| 4 | 端到端评估：改进 tracker + MLP predictor | 1 次 pipeline run |
