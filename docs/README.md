# 记录入口

本地编写代码；模型训练与评估在 Colab 执行。每轮从[当前行动](active_plan.md)开始；旧日期段落按历史快照阅读。规则见[AGENTS.md](../AGENTS.md)和[实验记录规范](experiment_iteration_protocol.md)。

| 位置 | 只负责什么 |
|---|---|
| [当前行动](active_plan.md) | 当前状态、迭代链接、唯一主要下一步 |
| [迭代记录](iteration_records/TEMPLATE.md) | 上轮依据、本轮改动、运行证据、结论与限制；新一轮复制模板 |
| [实验档案](../ai_runs/) | 一次实际运行的原始指标、日志和上下文；时间戳目录为准 |
| [关键事件日志](daily-log.md) | 模型、训练、评估、指标口径或研究结论的关键变化 |
| 阶段总结 | 多轮可比结果；每个结论链接实际运行及评价协议 |
| Git / PR | 文件版本与审阅记录；未提交内容不等于远端已同步 |

开始前，在迭代记录写上一轮证据、问题、目标及验证标准。执行后，记录实际代码版本、配置、数据划分、checkpoint、运行状态、原始指标与缺失证据。失败和重试各保留独立记录；没有训练时写“未执行”，不要创建伪实验或移动 `latest_run.txt`。收尾时说明结论是否成立，并更新当前行动。

普通阅读、分支查询和文档整理由迭代记录或 Git 差异承载；关键事件才写入日志。需要历史成果时引用固定提交的资料，避免复制出第二份可变总结。审计分支已有日志在整合时须保留。新记录使用 Asia/Shanghai，引用旧记录保留原时区；勿记录密钥或临时认证链接。
