> **创建日期**：2026-06-25

> **关联文档**：[model_definition.md](model_definition.md) · [experiment_protocol.md](experiment_protocol.md) · [eval_pipeline_analysis.md](eval_pipeline_analysis.md)

---

## 1. 总体目标

训练一个基于 MVDet 架构的多视角 BEV 行人检测模型，能够：

1. 从 WildTrack 7 路同步摄像头图像中，准确预测 BEV 视角下的行人占据热力图。
2. 热力图中的高亮区域（高光点）应与真实行人的地面位置精确对齐。
3. 从热力图中提取行人点检测，达到可用的检测精度。

---

## 2. 量化指标目标

### 2.1 最低可用标准

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **MODA** | ≥ 0.30 | 多目标检测准确率，综合考虑漏检和误检 |
| **Precision** | ≥ 0.50 | 检测点中至少一半是真实行人 |
| **Recall** | ≥ 0.40 | 至少能检出 40% 的行人 |
| **F1** | ≥ 0.40 | Precision 与 Recall 的调和均值 |

### 2.2 理想目标（参考 MVDet 论文）

MVDet 原始论文在 WildTrack 数据集上报告的指标：

| 指标 | MVDet 论文值 | 说明 |
|------|-------------|------|
| **MODA** | 0.888 | 论文最优结果 |
| **MODP** | 0.752 | 定位精度 |
| **Precision** | 0.945 | — |
| **Recall** | 0.938 | — |

本项目作为 MVDet-style 简化实现，短期内不要求达到论文水平，但应向这个方向持续优化。

### 2.3 训练过程监控指标

| 指标 | 健康范围 | 含义 |
|------|----------|------|
| **SNR** | ≥ 1.0（目标 ≥ 2.0） | 正样本区域平均 logit 与背景区域平均 logit 之差。越高说明模型区分行人和背景的能力越强 |
| **raw_pos_mse** | 持续下降 | 正样本区域（行人位置）的预测误差 |
| **raw_neg_mse** | 保持低位（< 0.01） | 背景区域的预测误差，应远小于 raw_pos_mse |
| **pred_raw max** | 接近 1.0 | 模型对行人位置的最大预测值应接近 GT 峰值 1.0 |
| **pred_raw mean** | < 0.15 | 整个 BEV 网格的均值应偏低（背景占绝大多数面积） |

## 3. BEV 热力图预期效果

### 3.1 理想效果

```
┌──────────────────────────────────────────────┐
│  BEV 预测热力图            BEV Ground Truth  │
│                                              │
│    ·  ··                    ●  ●●            │
│        ·                        ●            │
│                                              │
│      ·    ·                  ●    ●          │
│                                              │
│  · ·                        ● ●              │
│         ·                         ●          │
│                                              │
│  · = 预测高光点              ● = GT 行人位置  │
│  高光点与 GT 位置一一对应、位置吻合            │
└──────────────────────────────────────────────┘
```

- 每个真实行人位置对应一个独立的高光点（高响应区域）。
- 高光点的中心与行人的地面真实位置偏差 < 0.5m（MODP 衡量）。
- 背景区域保持低响应，没有孤立的假阳性高光点。
- 高光点之间互不粘连——相邻行人应产生可分辨的独立峰。

### 3.2 当前问题

当前训练 20 epoch 后的模型（Run #46, SNR=0.568）存在以下问题：

| 问题 | 表现 | 原因分析 |
|------|------|----------|
| 高光点不够突出 | 正样本区域平均 logit 仅比背景高 0.57 | SNR 过低，模型未充分区分行人和背景 |
| 预测值偏离 GT | pred_raw max ≈ 1.9（GT 峰值=1.0） | 部分位置过拟合，但整体正区域均值仍低 |
| 未获得有效检测指标 | eval 从未成功完成 | 评估管线的 argparse bug 和 Google Drive 限速 |

### 3.3 不可接受的效果

- **全图弥漫高响应**：背景区域与行人区域的响应值无明显差异，说明模型未学到空间区分能力。
- **高光点位置偏移**：预测的热点集中在非行人区域（如场景边缘），与 GT 不对齐。
- **严重漏检**：大量行人位置无响应，Recall < 0.10。
- **高光点粘连**：相邻行人的响应合并成一片，无法分离为独立检测点。

## 4. 调优方向

当 eval 指标低于目标时，按以下优先级排查和调整：

### 优先级 1：评估管线正确性

在调整模型之前，必须确认评估管线本身是正确的：

- 阈值范围覆盖 raw logit 的有效区间（当前模型约 -0.5 ~ +0.5）。
- NMS 方法和参数与 MVDet 一致（距离贪心抑制，dist_thres=5 cells）。
- 不在 raw logit 上额外做 sigmoid（已修复）。
- 详见 [eval_pipeline_analysis.md](eval_pipeline_analysis.md)。

### 优先级 2：提升 SNR

| 手段 | 说明 | 注意事项 |
|------|------|----------|
| 增大 `bev_pos_weight` | 当前 10.0，可试 50、100 | 过大可能导致背景抑制不足 |
| 增加训练 epoch | 当前 20，可试 50、100 | 观察 SNR 是否还在上升趋势 |
| 调整学习率 schedule | 尝试 warmup + cosine decay | — |
| 检查 GT 高斯 sigma | 当前 σ=5.0（MVDet 一致） | 不建议轻易修改 |

### 优先级 3：减少误检

| 手段 | 说明 |
|------|------|
| 增大 NMS 抑制半径 | 避免一个行人产生多个检测点 |
| 降低 `max_preds` | 从 200 降至 50（MVDet 默认） |
| 增大 `bev_neg_weight` | 加强对背景区域的抑制 |

### 优先级 4：提升定位精度

| 手段 | 说明 |
|------|------|
| 检查标定精度 | 投影矩阵是否正确 |
| 检查 BEV 网格分辨率 | 当前 480×1440，与 MVDet 一致 |
| 可视化单视角 BEV 投影 | 确认各视角的投影重叠区域合理 |

## 5. 验收流程

一次训练实验的结果必须通过以下步骤才算有效：

```text
1. 训练完成，保存 model_final.pth
2. 运行 evaluate_main.py --report_detection
3. 确认 MODA、Precision、Recall、F1 数值
4. 生成 bev_prediction.png 热力图
5. 目视检查热力图与 GT 的对齐情况
6. 记录到 ai_runs/ 目录下的 ai_context.md
```

仅凭训练 loss 下降或 SNR 提升，不能宣称模型达标。**检测指标和可视化验证是必需的。**
